# StudyMate AI

**StudyMate AI — a tutor that learns the way you learn**[cite: 1]

StudyMate AI is a personal study assistant prototype that explains, adapts, and checks your understanding until a topic actually sticks[cite: 1]. Traditional classrooms often fall short due to rigid speeds, student disconnect, and a lack of 1-on-1 guidance[cite: 1]. StudyMate AI fixes this by offering help whenever you're ready to learn, with no fixed pace and no waiting for office hours[cite: 1]. 

## 🚀 Features

* **24/7 personal tutor:** Answers doubts instantly with simple, step-by-step explanations[cite: 1].
* **Adaptive difficulty:** Automatically adjusts depth based on how you respond[cite: 1].
* **Targeted practice:** Generates quick checks and summaries to fix weak spots[cite: 1].
* **Dark/Light Mode:** Seamlessly toggle between themes, with your preference saved locally[cite: 1].
* **Secure AI Integration:** Chat calls the model through a server-side proxy, ensuring API keys never reach your browser[cite: 1].

## 🎯 Expected Outcomes

* **100%** Tailored pace — move on only after mastering a topic[cite: 1].
* **3×** Better retention from bite-sized, interactive review[cite: 1].
* **Zero** Learning gaps — doubts get resolved immediately[cite: 1].
* **24/7** Support whenever you actually sit down to study[cite: 1].

## 👥 Who is it for?

* **School & college students:** For homework help, exam prep, and quick concept reviews[cite: 1].
* **Self-learners:** For picking up a new subject or skill independently, at any age[cite: 1].
* **Teachers:** Acts as a teaching assistant that helps track where a class is getting stuck[cite: 1].
* **Diverse learners:** Adapts explanation styles to fit different ways of learning[cite: 1].

## 🛠️ Tech Stack

* **Frontend:** Vanilla HTML, CSS, and JavaScript with interactive animations (cursor glow, cursor-tracking shine)[cite: 1].
* **Fonts:** Space Grotesk, Kalam, Inter, and IBM Plex Mono[cite: 1].
* **AI Model:** Powered by Groq utilizing the Llama 3.3 70B model[cite: 1].

## 💻 Getting Started

This repository contains the frontend prototype. To make the chat functional, you will need to set up the server-side proxy. 

1. Clone this repository.
2. Open `index.html` in your web browser to view the frontend prototype.
3. **Note on the Backend:** The chat widget expects a backend running locally at `http://localhost:3000/api/chat`[cite: 1]. You will need a Node.js/Express (or similar) server set up at this endpoint to securely route requests to the Groq API.
